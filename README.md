# 音乐管家（Music Manager）

一个开箱即用的 **本地音乐收藏管理与播放工具**。把 MP3 放进文件夹，它会自动扫描入库；调用大模型 API 一次性提取歌名、歌手、流派并生成歌词和封面；内置播放器支持歌词同步、点击跳转和多种播放模式。

![语言](https://img.shields.io/badge/language-Python-blue) ![界面](https://img.shields.io/badge/UI-Tkinter-orange) ![协议](https://img.shields.io/badge/license-MIT-green)

---

## 1. 项目解决什么问题

本地收藏的音乐常常面临这些痛点：

- **文件散乱**：歌曲零散堆在硬盘各处，没有统一管理入口；
- **信息缺失**：多数 MP3 没有内嵌歌词和封面，播放体验差；
- **整理费时**：手动为每首歌改标签、找歌词、配封面，工作量巨大且难以坚持；
- **隐私顾虑**：在线音乐平台需要登录、有广告、曲库还可能下架，而本地音乐没有这些问题，缺的只是一套好用的管理工具。

**音乐管家** 的答案是：把歌曲放进 `cangku/歌曲库`，程序自动扫描入库；再调用一次大模型 API（OpenAI 兼容接口），就能批量拿到歌曲信息、生成标准 LRC 歌词和封面；之后播放完全离线、本地完成。所有数据（歌曲、歌词、封面、配置）都保存在本地 `cangku` 目录，不依赖任何云端曲库。

## 2. 主要功能

| 模块 | 功能说明 |
| --- | --- |
| **本地曲库管理** | 一键导入 MP3；自动扫描 `cangku/歌曲库` 入库；按流派分类浏览；关键词搜索（匹配歌名/歌手） |
| **AI 智能处理** | 调用大模型提取歌名/歌手/流派，生成 LRC 歌词并设计封面；处理结果落盘缓存，之后播放不再重复调用，节省 token |
| **本地封面生成** | 根据 AI 给出的颜色与描述，本地绘制渐变风格封面，无需图片生成接口 |
| **音乐播放** | 播放/暂停/上一首/下一首；进度条拖动跳转；音量调节 |
| **歌词同步** | 解析标准 LRC 歌词，随播放高亮滚动；**点击任意一行歌词即可跳转到对应时间播放** |
| **播放模式** | 顺序播放 / 随机播放 / 单曲循环 三种模式一键切换 |
| **个性化设置** | 自定义程序首页名字；配置 API 地址/Key/模型；内置「测试连接」 |
| **文件管理** | 一键打开存储文件夹；右键修改流派、打开歌曲所在目录、删除歌曲（连同歌词与封面） |
| **自检能力** | 内置 `--selftest` / `--guismoke` 自测模式，便于排查环境问题 |

## 3. 安装方法

### 方式一：直接使用（推荐）

从本项目 **Releases** 页面下载打包好的 `音乐管家.exe`（Windows），双击即可运行。首次启动会自动创建 `cangku` 数据目录。

### 方式二：源码运行

**环境要求**

- Windows 系统
- Python 3.8 及以上

**安装依赖**

```bash
pip install requests pygame Pillow
```

**运行**

```bash
python music_app.py
```

（`tkinter` 为 Python 标准库自带，无需额外安装。）

**打包为 exe**（可选）

```bash
pip install pyinstaller
pyinstaller -F -w -i icon.ico -n 音乐管家 music_app.py
```

## 4. 使用方法

### 第一步：配置 AI 接口（用于歌词与封面，必选）

1. 点击右上角 **⚙ 设置**；
2. 填写 **API 地址**（支持任何 OpenAI 兼容接口，例如 `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1` 或火山方舟等）；
3. 填写 **API Key** 和 **模型名称**（如 `deepseek-chat`、`qwen-plus`、`glm-4-flash`）；
4. 点击 **测试连接**，提示「连接成功」后保存。

### 第二步：导入音乐

- 点击 **导入音乐** 选择 MP3 文件，程序会复制到 `cangku/歌曲库` 并自动入库；或直接把 MP3 放进 `cangku/歌曲库` 文件夹，重启后自动扫描。

### 第三步：AI 处理（提取歌词 + 生成封面）

1. 在左侧列表选中一首或多首歌曲；
2. 点击 **AI 处理**（或右键 → AI处理），确认后批量处理；
3. 处理完成后，歌词、封面已保存到 `cangku/歌词`、`cangku/封面`，同一首歌之后播放不再重复调用 API。

### 第四步：播放

- **双击**歌曲开始播放；点击歌词任意行跳转播放；
- 使用 **▶ / ⏸ / ⏮ / ⏭** 控制播放；拖动进度条定位；
- 点击播放模式按钮在「顺序 / 随机 / 单曲循环」间切换；
- 右键歌曲可修改流派、打开所在文件夹、重新 AI 处理、删除歌曲。

## 5. 输入输出示例

### 5.1 输入

导入一首 MP3，例如：

```
cangku/歌曲库/示例歌曲.mp3
```

AI 处理时，程序向模型发送的消息（OpenAI 兼容格式）：

```json
{
  "model": "your-model-name",
  "messages": [
    {
      "role": "system",
      "content": "你是一位专业的音乐信息处理助手。用户会提供一首歌曲的文件名，请提取歌曲名和歌手、判断风格，输出LRC格式歌词和封面设计参数……"
    },
    {
      "role": "user",
      "content": "歌曲文件名：示例歌曲.mp3\n请按系统要求输出JSON。"
    }
  ]
}
```

### 5.2 输出

**① 模型返回的 JSON**（程序解析后落盘）：

```json
{
  "title": "示例歌曲",
  "artist": "示例歌手",
  "genre": "流行",
  "lrc": "[00:00.00]第一句歌词\n[00:04.00]第二句歌词\n[00:08.00]第三句歌词",
  "cover_desc": "城市夜景，霓虹灯与暖色灯光，现代流行风格",
  "color1": "#AA0000",
  "color2": "#0033AA",
  "emoji": "🎵"
}
```

**② 生成的 LRC 歌词文件** `cangku/歌词/歌曲名.lrc`：

```lrc
[00:00.00]第一句歌词
[00:04.00]第二句歌词
[00:08.00]第三句歌词
[00:12.00]第四句歌词
```

播放时歌词按时间戳同步高亮，点击任一行即可跳转。

**③ 生成的封面文件** `cangku/封面/歌曲名.jpg`：根据 AI 提供的两个主色在本地绘制渐变背景 + 歌曲名/歌手名。

**④ 曲库索引** `cangku/library.json` 自动更新：

```json
[
  {
    "id": "示例歌曲",
    "file": "示例歌曲.mp3",
    "title": "示例歌曲",
    "artist": "示例歌手",
    "genre": "流行",
    "dur": 218,
    "has_lrc": true,
    "has_cover": true
  }
]
```

**⑤ 配置文件** `cangku/config.json`（保存程序设置）：

```json
{
  "app_name": "音乐小管家",
  "api_base": "https://your-api-host/v1",
  "api_key": "",
  "model": "your-model-name",
  "play_mode": "loop",
  "volume": 62
}
```

## 项目结构

```
音乐管家/
├── music_app.py          # 主程序（入口）
├── icon.ico              # 程序图标
└── dist/                 # PyInstaller 打包输出（不提交仓库）

cangku/                   # 数据目录（运行时自动创建，不提交仓库）
├── config.json           # 程序设置（含 API 配置）
├── library.json          # 曲库索引
├── 歌曲库/               # 存放 MP3
├── 歌词/                 # 每首歌一个 .lrc
└── 封面/                 # 每首歌一张 .jpg
```

## 技术栈

- **GUI**：Python Tkinter / ttk（深色主题）
- **播放**：pygame.mixer
- **封面绘制**：Pillow（PIL）
- **AI 接口**：requests 调用 OpenAI 兼容 Chat Completions API
